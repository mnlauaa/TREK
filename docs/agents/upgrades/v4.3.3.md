## Integration decisions

The comparison found 272 overlapping paths and 95 content-conflict paths, including 32 translation files, without modify/delete conflicts. Three-way formatter normalization removed formatting-only conflicts; semantic conflicts were reconciled by feature.

Core packages are 4.3.3; the standalone SDK is 1.7.1. The official migration chain ends at 244. The historical legacy-fork bridge stays at 200 and the four named fork migration IDs remain unchanged. Numeric official migrations 201–244 must execute after a legacy bridge.

### Exchange rates

Preserve explicit → trip → global priority, provenance and manual preview/apply/reset. Foreign creates require a valid rate; unrelated edits preserve the existing rate. The explicit `freeze-rates`/`freeze_budget_rates` writes retain editor permission checks and record provenance and actor. Opening Costs never calls them automatically.

Recognized provenance makes an explicit 1:1 a frozen rate; legacy 1 remains the no-rate sentinel. Missing legacy rates are excluded from settlement and reported through `unconverted`. Batch previews show an unknown old value as awaiting conversion with no fabricated difference. A stale preview is refused if the selected currency's rows or trip currency changed.

Keep upstream precision, final-budget details, receipts, payment dates, currency-bearing summaries and display-rate fallbacks. Keep mobile edit/delete with confirmation and a single payment ledger; timeline date recovery coexists with All Days on planner and Road trip maps.

### Other retained contracts

Use the original custom-commit inventory in [v4.2.1](v4.2.1.md): common currencies, guest identity transfer, Web Push, departure countdown/responsive layouts, zh-HK/traditional Chinese, debranding/Legal/Source, builder dependencies, pinned MinIO and fork Sonar configuration. The old map-source patch remains superseded. Release/support promotional notices remain retired. TREK Places retains the upstream default; other integrations retain their shipped defaults.
