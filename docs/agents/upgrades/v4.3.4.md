## Runtime security requirement

The release rebuilds TREK with patched Node.js. Its Git delta does not pin a new runtime. Both the upstream and fork Dockerfiles use floating Node 24 images, so a cached image or version-only deployment does not establish remediation.

[The Node.js advisory](https://nodejs.org/en/blog/vulnerability/october-2026-security-releases) identifies 24.22.1 as the patched 24.x release and 22.23.4 as the patched 22.x release. A release image must pull refreshed bases and verify the Node binary inside the completed image.

The first build timed out while fetching Docker Hub metadata. Public image pulls then failed with registry EOF responses. A task-local public-registry Docker configuration bypassed the stalled desktop credential helper without modifying the user's configuration. That build downloaded fresh bases but encountered an npm connection reset. Both production build retries succeeded. The completed upstream and fork images each run Node 24.22.1. The fork image ID is `sha256:c506ef4bd7e28b9d5cd996a4b84ea7c173fc17b0d61dfeb14a0901186bc4a2b5`; the control image ID is `sha256:e821e356ce4fb3d7ae7594e79fde12dbb02f5d1902637341fa1de16468c88bae`. Both use runtime base digest `sha256:43b9ba1142b8dcf33fa8f922ca1be85714adc444e0586c7cf7726daaeabc1bea`. These are local validation images, not published release images. The candidate still has the default repository source URL; release publication must rebuild with its committed immutable source URL.

The Helm chart still defaults to the upstream image repository. A fork deployment must explicitly select its own rebuilt image and tag. The default chart version alone does not preserve fork behavior.

The user accepted this pinned unsigned release and authorized the commit and PR to `dev`. That acceptance does not authorize production promotion. Production promotion remains separate and requires a current complete backup, write-stop plan, encryption/plugin coverage, smoke checks and an explicit rollback image. Rollback restores the complete pre-upgrade data together with its old image.
